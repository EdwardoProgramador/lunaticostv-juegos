## Consejos de generación (GPT Image 2)

1. **Genera a máxima resolución** disponible y redimensiona tú después — la calidad del upscale importa.
2. **Iterar en lotes de 4** con el mismo prompt: escoge el mejor, no te quedes con el primero.
3. **Palette lock**: si la imagen sale muy azul eléctrico, añade `restrained, subtle use of #3A5BFF only as rim light — dominant palette is Midnight #060814 and Indigo #0B1024`.
4. **Pieles naturales**: GPT Image 2 a veces satura las pieles en azul. Si pasa, añade `warm subsurface scattering in skin, natural Latin American skin tone, accurate melanin reproduction`.
5. **Consistencia de mundo**: todas las imágenes deben sentirse de la misma película. Reutiliza el stack `shot on ARRI Alexa 35, Zeiss Supreme Prime anamorphic lenses, 35mm film grain, deep blacks, cool teal-navy shadows`.
6. **No texto**: GPT Image 2 tiende a meter letras inventadas. El closer `no text, no letters, no logo` al final del prompt ayuda mucho.
7. **Si una imagen sale warm/amarilla**, añade al final: `CRITICAL: no warm tones, no yellow, no orange, strictly cool navy and electric blue palette`.

## Flujo de trabajo recomendado

1. Empieza por `hero.png` (es la más importante). Itera hasta que esté perfecta.
2. Luego las 3 de `now-*.png` — que se sientan del mismo universo.
3. Luego las 6 `poster-*.png` — pueden tener más variedad estilística.
4. `format-vertical/horizontal` — son para los mockups, así que no necesitan ser obras maestras.
5. `creators.png` y `cta.png` al final.

Cuando tengas las imágenes, sólo arrástralas a `img/` con el nombre exacto y la landing las recogerá sola.

## GPT Image 2 — Documentación API (resumen)

Modelo recomendado para generación y edición de alta calidad: **`gpt-image-2`**. Descripción oficial: modelo de generación de imágenes de última generación, buena fidelidad y tamaños flexibles. Referencias: [Modelo GPT Image 2](https://developers.openai.com/api/docs/models/gpt-image-2), [Guía de generación de imágenes](https://developers.openai.com/api/docs/guides/image-generation), [Guía de prompting multimodal](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide).

**Endpoints (Image API)**

- Generación: `POST https://api.openai.com/v1/images/generations`
- Edición: `POST https://api.openai.com/v1/images/edits`

**Parámetros útiles (salida)**

| Parámetro | Notas |
| --- | --- |
| `model` | `"gpt-image-2"` |
| `prompt` | Texto del plano visual (en inglés suele ir bien; tus prompts de arriba ya están listos para pegar). |
| `size` | Ejemplos: `1536x1024`, `1024x1536`, `3840x2160`, `2160x3840`, o `auto`. Restricciones: arista máx. **3840px**, ambas dimensiones **múltiplo de 16**, ratio largo/corto **≤ 3:1**, píxeles totales entre **655 360 y 8 294 400**. |
| `quality` | `"low"` (borradores rápidos), `"medium"`, `"high"` o `"auto"`. Para stills finales del sitio usa **`high`** cuando el presupuesto lo permita. |
| `n` | Número de imágenes por request (por defecto 1). |
| Formato | Por defecto PNG; también **JPEG** o **WebP** (JPEG puede ser más rápido). |

**Importante**

- **`gpt-image-2` no soporta fondo transparente** (`background: "transparent"` no aplica).
- Resoluciones **por encima de ~2560×1440 (2K)** pueden considerarse **experimentales** en la guía: prueba primero en 2K y valida antes de encadenar muchos 4K.
- Puede haber **hasta ~2 min** de latencia en prompts complejos.
- **Texto dentro de la imagen** sigue siendo frágil; por eso en tus prompts va el cierre **`no text, no letters, no logo`**.

**Ejemplo mínimo (Node)**

```javascript
const result = await openai.images.generate({
  model: "gpt-image-2",
  prompt: "…tu prompt en inglés…",
  size: "1536x1024",
  quality: "high",
});
// Guardar: result.data[0].b64_json → archivo .png
```

**Organización y verificación**

Antes de usar modelos GPT Image en la API puede ser necesaria la [verificación de organización](https://help.openai.com/en/articles/10910291-api-organization-verification) en la consola de OpenAI.

**Flujo recomendado con esta carpeta**

1. `quality: "low"` + `size` moderado para iterar prompts.  
2. Cuando cierre look y composición, un batch con `quality: "high"` y el `size` de la tabla de arriba (`IMAGE-PROMPTS.md`).  
3. Exporta PNG, renombra exacto (`hero.png`, etc.) y coloca en `img/`.
